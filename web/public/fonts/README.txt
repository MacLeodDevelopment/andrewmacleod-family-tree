Fonts
=====

Self-hosted web fonts, Latin subset only, downloaded from Google Fonts as
variable woff2 files.

schibsted-grotesk-latin.woff2
  Schibsted Grotesk, weights 400-900 (variable)
  https://fonts.google.com/specimen/Schibsted+Grotesk
  SIL Open Font License 1.1

martian-mono-latin.woff2
  Martian Mono, weights 400-500 (variable)
  https://fonts.google.com/specimen/Martian+Mono
  SIL Open Font License 1.1

Full license text: https://openfontlicense.org/open-font-license-official-text/

Characters outside the Latin range (for example the arrows used in links)
fall back to system fonts.
